\# PulseIQ Analytics



Workforce analytics and BI project (WorkforceOS Section 3, Data Analysts track) by Shaikh Naved.



\## Structure



| Folder | Tasks | What it covers |

|---|---|---|

| phase-1/ | PQ-01 to PQ-05 | ETL pipeline with data contracts, star-schema warehouse, data-quality gate, metric layer, workforce dashboard |

| phase-2/ | PQ-06 to PQ-10 | Attendance and leave, attrition, team productivity, payroll cost, budget vs actual |

| phase-3/ | PQ-11 to PQ-15 | P\&L and expenses, receivables and cash, cross-department impact, AI signals, executive scorecard |



Each phase folder has its own README with the details, the screenshots (in docs/) and how to run it.



\## Reports



The Phase 1, Phase 2 and Phase 3 reports are submitted as separate PDFs.
